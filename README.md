# SFSB Group — Premium Germany Visa Consultancy Prototype

## Design direction
This version restores the earlier preferred visual identity: midnight navy, crisp white, electric-blue accents, subtle German tricolour detail, premium glass-style floating cards, and the original Germany city photography.

## Separate pages
- `index.html` — Homepage
- `explore.html` — Visa pathways
- `about.html` — About SFSB Group
- `process.html` — How it works
- `guides.html` — Visa guides and FAQs
- `contact.html` — Contact and enquiry
- `dashboard.html` — Separate consultant dashboard (footer link only)

## Preview
Keep the `assets` folder beside all HTML files. Open `index.html` in a browser. The Google Fonts and Unsplash images load from the internet.

## Demo functionality
- Responsive mobile navigation
- English, German and Spanish language selector
- Visa guide modal previews
- Four-step enquiry modal
- Contact form creates a WhatsApp handoff
- FAQ interactions and search
- Separate dashboard with editable sample leads and demo Kanban/table views
- Scroll reveal and hover animations

## Production checklist
This is a front-end prototype, not a live case-management system. Demo dashboard data is fictional and changes are local to the browser. The enquiry flow does not store data in a secure database. Production requires secure authentication, role-based access, server-side validation, database integration, privacy/consent review, and verified official visa content.

Please verify the company brand spelling, contact email/domain spelling, telephone number and address before public launch. Visa outcomes are never guaranteed; decisions are made by the competent authorities.
